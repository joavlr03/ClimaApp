# 🌦️ ClimaApp

Aplicativo Android para consulta de informações climáticas, desenvolvido como projeto de estudo e evolução prática em **Kotlin** e **Jetpack Compose**.

> 🚧 **Status: Em desenvolvimento**
>
> O projeto está sendo construído gradualmente. Novas funcionalidades, integrações e melhorias serão adicionadas ao longo do desenvolvimento.

## 🎯 Objetivo

O objetivo do ClimaApp é desenvolver uma aplicação Android capaz de apresentar informações meteorológicas de forma simples e intuitiva, utilizando dados obtidos por meio de uma API externa.

Além da aplicação final, o projeto está sendo utilizado para aprofundar conhecimentos em:

* Desenvolvimento Android moderno
* Kotlin
* Jetpack Compose
* Arquitetura de aplicações mobile
* Consumo de APIs REST
* Injeção de dependências
* Navegação entre telas
* Tratamento e organização de dados

## 🛠️ Tecnologias

| Tecnologia             | Utilização                   |
| ---------------------- | ---------------------------- |
| **Kotlin**             | Linguagem principal          |
| **Jetpack Compose**    | Construção da interface      |
| **Navigation Compose** | Navegação entre telas        |
| **Hilt**               | Injeção de dependências      |
| **Android SDK**        | Desenvolvimento da aplicação |

## 📚 Aprendizados

O ClimaApp faz parte da minha jornada de aprendizado em desenvolvimento de software e tem como objetivo transformar conceitos estudados em uma aplicação prática.
